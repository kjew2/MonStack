# Lineage UI concepts

Two self-contained, interactive visual explorations for MonStack’s breeding lineage flow. Open either HTML file in a browser; all artwork, scripts, and styles are embedded. No game save is read or changed.

- **Library:** selected lineage detail, I–X progression, V/X previews, then guided parent selection, offspring review, training contribution, and breakthrough preview.
- **Workshop:** the same decisions arranged around two parent cards, their prospective offspring, and a persistent generation milestone rail.

The dark palette is an optional visual direction. These are concept mockups, not screenshots of the production UI. Example data focuses on Fortune IV → V; the other library entries are illustrative samples rather than the full production catalogue. Breakthrough success is scripted, and training explicitly jumps to a later qualifying seal.

Both show 140/180 lineage points, 50-shard breeding cost, retained parents, 12-point capstones, 20-point complete trees, 50% initial V breakthrough odds with pity, and the locked X Shared Fortune milestone. Node-only progress and inheritance at birth remain explicit.

`*-overview.png` files show the desktop layout; `*-mobile.png` show the 390px layout. Browser verification covers the complete action flow, all six stages at 390px without document overflow, and JavaScript errors.
